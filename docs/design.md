# ルミア島の地下迷宮

## 概要

- ゲーム「エターナルリターン」の二次創作ゲーム。
- ローグライクゲーム。いわゆる「不思議なダンジョン」系のゲーム。

## 環境

- Webブラウザで動かせるアプリケーションとして作成。

### アーキテクチャ

| 要件 | 実装方法 |
|-|-|
| 実行環境 | ブラウザ JavaScript |
| 開発言語 | JavaScript（TypeScriptではない） |
| ベースライブラリ | Phaser3 |

### プロジェクト構造

- lumia-underground-labyrinth
	- assets ... ゲームで扱う素材を格納。
		- data ... ゲームで扱うデータファイルを格納。
		- audio ... BGM、SEを格納。
		- image ... 画像素材を格納。
		- lib ... ライブラリを格納。
	- docs ... 設計資料を格納。
	- src ... スクリプトファイルを格納。
	- index.html ... ゲームを表示するためのhtmlファイル。

## ゲーム設計

- ゲームスクリーンサイズは、ベースは横1280、縦720。
	だが、比率はそのままで可変できるように。
- ゲームスクリーンはhtmlの上中央に表示。

### 操作

- 矢印キー ... 8方向移動、持ち物画面内の選択・ページ切り替え、投擲方向の選択。
- Z ... 通常時は1ターン待機。持ち物画面では選択・決定。
- X ... 通常時は足元のアイテムを拾う。コマンド選択中はコマンド選択だけを閉じ、持ち物画面では閉じる。
- C ... 通常時は持ち物画面を開く。持ち物画面ではアイテムを分類順に整頓。
- V ... 押している間、地図を表示。

### 表示UI

- 画面左上のステータスUIには、フロア、レベル、HP、満腹度、現在の攻撃力、防御力を表示する。
- フロア表示の下に、装備中の武器、遠距離武器、防具、装飾を表示する。未装備の欄は「なし」と表示する。
- 画面右下に最大8件の行動ログを表示する。ログは5秒後に消える。
- 長い行動ログは枠内で文字単位に折り返す。折り返し後にログ領域へ収まらない古いメッセージは表示しない。

### ダンジョン生成設計

- ダンジョンは、全体を横64マス、縦64マスとする。
- 縦横16マスで分割し、縦横4つのエリアを作る。
- エリア内に長方形の部屋を作成する。部屋はエリアをはみ出ないようにする。
- 部屋の最小サイズは縦横5マス、部屋の最大サイズは縦横12マスとする。
- 全体の部屋の数は最低8、最大12とする。
- 全ての部屋が何等かのルートでたどり着けるように、通路を作成する。
- 通路は交差してもよいが、幅1マスとし、
	部屋の端壁とくっ付いたり通路どうしが平行に隣接してはいけない。

#### 描画

- マップタイルは16x16マス単位のRenderTextureチャンクとして描画する。
- 1マスの大きさは64pxとする。
- キャラクターと敵シンボルはY座標に応じた描画順とし、同じY座標では敵本体、敵シンボル、主人公の順に手前へ表示する。

### 画像設計

- CharaXXXX.png ... キャラクター画像。（味方・敵）256 x 256。
- MapChip.png ... マップチップ画像。64 * 4 x 64。
	左から壁、下が床の場合の壁、床1、床2。
	床2は装飾として、ランダムに少し配置する。

### アイテム設計

- 所持品は最大20個まで保持でき、同一アイテムも別枠で保持する。スタックはしない。
- 持ち物画面は10枠ずつの2ページ表示とする。主人公が床アイテムの上にいる時は、足下アイテムを表示する3ページ目を追加する。矢印上下で選択、矢印左右でページを切り替える。
- 足下アイテムはすべての分類で「拾う」を先頭コマンドとして表示する。「拾う」は、持ち物画面を閉じてXキーで拾う時と同じ処理を行う。足下アイテムは手持ちと同様に食べる、使う、投げる、製作ができる。装備、外す、置くはできない。
- 持ち物画面では、Cで分類・ID順に整頓できる。持ち物を開いた時点では並び替えない。
- 装備中の装備品を選択した場合、コマンドは「装備」ではなく「外す」とする。
- すべてのアイテムの選択メニューに「製作」を表示する。製作では素材を2つ選択し、`craft.csv`に組み合わせがあれば生成物へ変換する。組み合わせがなければ「うまく作れなかった！{first}と{second}は消失した。」と表示して2つの素材を消失する。
- 2個目の素材を選んでいる間、1個目の素材は無効表示して選択できない。持ち物ウィンドウの枠を緑へ変更し、Xで1個目の選択メニューへ戻る。
- アイテムは床に分類別のアイコンで表示し、視界外では非表示にする。主人公が床アイテムの上へ移動した場合、空き枠があれば自動で拾う。
- アイテムを置くと主人公の足元へ配置する。
- 投擲の射程は最大10マスとし、壁または最初に当たった敵で止まる。投擲中は他の操作を受け付けない。
- 投擲が外れた時や敵のドロップ先にアイテムがある場合、周囲8マスの歩行可能でアイテムのないマスへランダムに落とす。周囲8マスに空きがなければ5x5マスの範囲へ広げ、それも空きがなければアイテムは消失する。
- 通常の投擲ダメージは5とする。草を敵に当てた場合は、その草の効果を敵に適用する。HP回復は敵の最大HPを超えない。
- 睡眠ガス弾は「使う」で方向を選択し、最初に当たった敵と周囲8マスの敵を5ターンの睡眠状態にする。すでに睡眠中の敵の残りターンはリセットしない。
- 使用・食べる行動では、基本のHP・満腹度回復後に使用時効果を適用する。回復量と最大値増加による回復量は別に扱い、最大値増加による回復ログは表示しない。
- 最大HPまたは最大満腹度が増加した場合、増加量と同じ値だけ現在HPまたは現在満腹度も回復する。
- 装置系アイテムは、`item.csv` の使用可能回数最小・最大から初期使用回数をランダムに決定する。使用ごとに残り回数を1減らし、0回になると消失する。
- 感情のコップは使用時に、主人公と同じ部屋にいる敵を8ターン混乱状態にする。主人公が通路にいる場合は、周囲8マスの敵を対象にする。
- ジャンプパッドは使用時に、現在いる部屋以外のランダムな部屋にある、敵と階段のないランダムなマスへ主人公を移動させる。

#### アイテムデータ

- `assets/data/item.csv` にアイテムの基本値と使用時効果IDを定義する。
- `assets/data/item-effect.csv` に使用時効果IDと説明を定義する。
- `assets/data/craft.csv` に製作ID、素材1ID、素材2ID、生成物IDを定義する。素材の選択順は問わない。
- 現在実装済みの使用時効果IDは以下とする。
	- `0` ... 満腹度が満タンの時に使うと、最大満腹度が1増加する。
	- `1` ... 満腹度が満タンの時に使うと、最大満腹度が2増加する。
	- `2` ... 満腹度が満タンの時に使うと、最大満腹度が3増加する。
	- `20` ... HPが満タンの時に使うと、最大HPが2増加する。
	- `21` ... HPが満タンの時に使うと、最大HPが3増加する。
	- `22` ... 使用者を5ターンの睡眠状態にする。敵へ投げて当てた場合はその敵を睡眠状態にする。
	- `23` ... 現在いる部屋以外のランダムな部屋のランダムな位置へ移動する。
	- `24` ... 使用者の混乱状態を解除する。
	- `25` ... 鈍足状態ではない使用者を8ターンの加速状態にする。鈍足状態の場合は、加速状態にせず鈍足状態を解除する。
	- `26` ... 加速状態ではない使用者を10ターンの鈍足状態にする。加速状態の場合は、鈍足状態にせず加速状態を解除する。
	- `53` ... 使用者をそのフロアの間、罠避け状態にする。罠避け状態では罠を踏んでも発動しない。
	- `54` ... 同じ部屋にいる敵を40ターンの麻痺状態にする。通路にいる場合は周囲8マスの敵を対象にする。
	- `55` ... 撃つ方向を選択し、その直線上の射程10マス以内にいる敵すべてへ50ダメージを与える。
	- `56` ... 撃つ方向を選択し、その方向へ壁または敵の直前まで瞬時に移動する。射程は無限で、斜め移動時の角は無視する。
	- `51` ... 同じ部屋にいる敵を8ターンの混乱状態にする。通路にいる場合は周囲8マスの敵を対象にする。
	- `52` ... 現在いる部屋以外のランダムな部屋のランダムな位置へ移動する。
	- パン、肉、じゃがいも、タラ、ポテトフライ、フィッシュカツは効果ID `0`、ハンバーガーは効果ID `1`、フィッシュ＆チップスは効果ID `2`、薬草は効果ID `20`、ハーブは効果ID `21`、眠り草は効果ID `22` を使用する。

### 主人公設計

- フロア開始時、主人公はダンジョン内のランダムな部屋にスポーンする。
- プレイヤーと敵の通常攻撃は、基本命中率90%とする。
- アイテムの投擲は、基本命中率80%とする。敵への投擲が外れた場合、アイテムはその敵の足元に落ちる。
- 種別 `10` の遠距離武器を装備中、Aキーを押しながら方向キーを入力すると、射程10マスの直線上にいる最初の敵へ遠距離攻撃する。ダメージは `max(1, 攻撃力 - 防御力)` とし、使用回数を1消費する。使用回数が0になると「{item}を使い切った。」と表示して消失する。
- 主人公の初期HPは20、初期攻撃力は3、初期満腹度は100。
- レベルアップごとにHPが3～5、攻撃力が1加算される。
- 経験値は累積で管理し、レベルアップに必要な経験値は前レベルの1.5倍（小数点以下切り上げ）とする。レベルゲージは現在のレベルから次のレベルまでに必要な経験値に対する進行度を表示する。`start-level` 指定時も、そのレベルの開始時点から表示する。
- 満腹度は10歩歩くごとに1減る。満腹度が0の場合、毎ターン1ダメージを受ける。

- 満腹度がある状態でターンを消費すると回復する。最大HP100で毎ターン1、最大HP200で毎ターン2、
	最大HP50で2ターンに1回1回復するようなグラフとする。
	ただし、満腹度が0の場合は回復しない。
- Shiftを押しながら8方向へ移動するとダッシュする。開始後はShiftを離しても、壁または敵にぶつかるまで同じ方向へ移動を続ける。床アイテムのマスに到達した場合は拾わずにダッシュを停止し、「{item}に乗った。」と表示する。敵と隣接した時、敵から攻撃を受けた時、部屋または通路へ入った時もダッシュを停止し、ダッシュ中の主人公の移動速度は通常時の約2倍とする。
- 最大フロア以外には階段を1つ生成する。階段に乗るか階段の上でXを押すと次フロアへ進む確認を表示し、「はい」でフェードアウト後に次のフロアへ移動し、フェードインする。階段マスにはアイテムを置けず、置く・ドロップ・投擲の着地点が階段の場合は周囲の空きマスへ落とす。
- 所持品が満杯で床アイテムのマスに乗った場合は「{item}に乗った。」と表示する。満杯の状態でXにより拾おうとした場合は「持ち物がいっぱいで、{item}を拾えない。」と表示する。
- 20個までアイテムを持つことができる。
- つるはしまたは黄金のつるはしを装備中、上下左右の壁へ移動しようとすると、その壁を通路へ掘り進めて1ターン消費する。掘削のたびに、つるはしは5%、黄金のつるはしは2%の確率で消失する。斜め方向への掘削はできない。

#### ターン進行

- 主人公の移動、通常攻撃、待機、アイテムの使用、置く、拾う、投擲は1ターンを消費する。
- 主人公の行動後に敵の行動を解決する。
- 移動と攻撃には短いアニメーションを付け、アニメーション中は操作を受け付けない。

#### 戦闘

- 主人公が敵のいるマスへ移動しようとすると通常攻撃を行う。
- ダメージは `max(1, 攻撃力 - 防御力)` とする。
- 主人公と敵の通常攻撃は命中時のみダメージを与え、外れた場合はメッセージログへ出力する。
- ウィンドランナーを装備中、主人公の通常攻撃時に20%の確率で同じ敵へ追加でもう1回通常攻撃する。最初の攻撃で敵を倒した場合は追加攻撃しない。
- ハデスエッジまたはダインスレイヴを装備中、主人公の通常攻撃が命中すると、与えたダメージの30%（小数点以下切り捨て）をHPとして回復する。
- 防弾チョッキを装備中、遠距離攻撃のダメージを50%軽減する。効果ID `202` の装備は遠距離攻撃のダメージを75%軽減し、両方を装備している場合は75%軽減を優先する。効果ID `203` の装備はセリーヌの爆弾、地雷などの爆発物ダメージを固定ダメージを含めて50%軽減する。
- 効果ID `4` の装備を着用中、主人公は平和状態にならない。効果ID `5` の装備を着用中、主人公は平和状態および麻痺状態にならない。
- 効果ID `204` の装備を着用中、主人公は混乱状態にならない。レノアの範囲混乱とアディナの魔法弾による混乱が無効になる。
- 効果ID `205` の装備を着用中、主人公は睡眠状態にならない。眠り草、バーニャの睡眠風、アディナの魔法弾による睡眠が無効になる。
- 投擲が敵に外れた場合、投げたアイテムを敵の足元へ落とし、メッセージログへ出力する。


#### 視界

- 部屋内では部屋全体と、部屋と隣接する1マス分が可視状態。
- 通路では周囲8マスが可視状態。
- 可視状態でないマスは、暗く表示され、敵やアイテム、罠も見えない。

#### ミニマップ

- 発見済みの床と通路を表示する。Vを押している間は全画面の地図オーバーレイを表示する。
- 視界内の床アイテムは暗い緑、罠は白い `X`、敵は赤、主人公は黄で表示する。罠はアイテムと同じ優先度で描画する。階段は一度視界に入ると、以降は視界外でも白塗り・黒枠で表示する。
- マーカーのサイズはすべて同じとする。描画優先順位は主人公、敵、アイテムの順とする。

### 敵設計

- `assets/data/enemy.csv`に情報を定義。
- 以下カラム定義
	- ID ... 敵の識別番号。
	- 名前 ... メッセージ等で表示する敵の名前。
	- 画像ファイル ... 表示する画像ファイル。
	- 進化先ID ... レベルが上がった時変化する敵のID。
	- シンボル ... ある場合は、敵の右下にシンボルの画像が表示される。
	- HP ... 敵の体力。
	- 攻撃力 ... 敵の攻撃力。
	- 防御力 ... 敵の防御力。
	- 経験値 ... もらえる経験値量。
	- 移動回数 ... 敵が1ターンに移動することができる回数。
	- 攻撃回数 ... 敵が1ターン中に攻撃することができる回数。
	- 特殊能力ID ... `enemy-skill.csv`で定義した特殊能力のID。無ければ空欄。
	- 備考 ... 追記事項。無ければ空欄。

#### 敵スキルデータ

- `assets/data/enemy-skill.csv` に特殊能力IDと説明を定義する。
- 特殊能力の発動条件は説明文ではなく、特殊能力IDで判定する。
- 特殊能力IDは、その能力を持つ通常種の敵IDと一致させる。通常種と進化段階が同じ能力を使う場合は通常種の敵IDを共有し、ゴールド個体だけが持つ専用能力はそのゴールド個体の敵IDを使用する。能力の最新IDと説明は `assets/data/enemy-skill.csv` を正とする。
- スキルID `0` は、HPが0以下になるダメージを受けても1回だけHP1で耐える効果とする。
- スキルID `0` が発動した場合、「{enemy}はニナとの生命共有で耐えた！」と行動ログへ表示する。
- クロエ系の敵はスキルID `0` を持つ。
- スキルID `1` は、倒した時にパン、肉、じゃがいも、タラのいずれかを必ず敵の足元へ落とす効果とする。
- スキルID `1` が発動した場合、「{enemy}は{item}を落とした。」と行動ログへ表示する。
- シウカイ系の敵はスキルID `1` を持つ。

#### 敵の行動

- 敵は主人公を視界内に捉えると、最短経路で主人公へ接近する。
- 主人公を見失った敵は、最後に把握した主人公位置を最大2ターン追跡する。
- 追跡対象がない敵は通路を優先しつつ巡回する。
- 主人公に隣接した敵は、敵データの攻撃回数まで通常攻撃する。
- 敵の移動回数と攻撃回数は、敵データで定義する。
- フロアの敵数が上限未満の場合、`enemy-map`で定義したリスポーン間隔ごとに敵を1体出現させる。
- `enemy-map` の `<リスポーン間隔>` の後ろに任意で `|モンスターハウス確率|` を指定できる。抽選に当たると、主人公の初期部屋以外の1部屋をモンスターハウスにし、部屋内の66%以上のマスに敵とアイテムを配置する。モンスターハウスの敵はすべてスポーン睡眠状態で配置し、侵入時に必ず起床する。侵入時は「集中実験室だ！」と表示し、その後はミニマップに全敵の位置を常に表示する。

### 状態異常


- 睡眠（スポーン） ... 行動しない。同じ部屋に入った瞬間、50%の確率で起きる。
	隣接した場合、50%の確率で起きる。攻撃されると100%起きる。
- 睡眠 ... 行動しない。攻撃されても起きない。5ターン後に起きる。主人公には `Zz` を表示し、睡眠中は操作を受け付けず自動でターンをスキップする。解除は次の主人公ターン開始前に行い、解除自体ではターンを消費しない。主人公と視界内の敵が睡眠になった時と通常睡眠から起きた時は、行動ログにメッセージを表示する。スポーン睡眠からの起床時は表示しない。
- 混乱 ... 8ターン継続する。主人公は方向入力時にランダムな8方向へ移動または攻撃する。ランダムな移動先が壁の場合もターンを消費する。アイテム使用・投擲の方向選択には影響しない。敵はランダムな方向へ移動し、隣接する主人公または他の敵がいる場合は50%の確率で攻撃する。混乱中は右上に `?` を表示する。解除時は「{target}の混乱はおさまった！」と行動ログに表示する。
- 洗脳 ... 次の主人公の行動時、隣接する空きマスへの移動、または所持アイテムを選んだ非製作アクションをランダムに強制する。方向指定が必要な行動はランダムな方向で実行する。
- 倍速 ... 8ターン継続する。倍速中の敵は移動回数と攻撃回数が2倍になり、右上に `>>` を表示する。ルク系の敵はアイテム所持中、持続ターンにかかわらず常時倍速状態となる。複数の状態マーカーが有効な場合は、`Zz`、`>>`、`?` を順番に切り替えて表示する。
- 鈍足 ... 10ターン継続する。主人公・敵ともに2ターンに1回しか行動できず、右上に `<<` を表示する。
- 麻痺 ... 40ターン継続する。主人公・敵ともに行動できず、右上に `#` を表示する。ダメージを受けた時点で解除される。
- 平和 ... 5ターン継続する。主人公は攻撃とアイテムの投擲ができず、アイテムの使用はできる。敵は攻撃とスキルが使えない。

### 装備時効果

- 生命探知機 ... 装備中はミニマップにフロア内のすべての敵位置を表示する。
- 双眼鏡 ... 装備中は通路での視界が周囲1マスから周囲2マスへ広がる。
- スポーツウォッチ ... 装備中は鈍足状態にならない。
- 再生腕輪 ... 装備中にHPが0になると、HP・満腹度を最大まで回復し、すべての状態異常を解除して消失する。行動ログに「再生腕輪により復活した！」と表示する。

### ダンジョンデータ設計

- `assets/data/dungeon-XXXX.dat`に情報を定義。
- 以下ファイル内容定義。
	```
		dungeon-name = {ダンジョン名}
		max-floor = {ダンジョンの最大フロア数}
		max-enemies = {フロアに存在できる最大の敵の数}
		start-level = {ゲーム開始レベル}
		start-floor = {ゲーム開始フロア}
		start-item = {ゲーム開始時に持つアイテムID}, {ゲーム開始時に持つアイテムID}, ...

		[enemy-map]
		{フロア}: [{初期敵数最低}-{初期敵数最大}] <{リスポーンターン間隔}> |{モンスターハウス確率}| {出現する敵ID}^{出現割合}, {出現する敵ID}^{出現割合}, ...

		[item-map]
		{フロア}: [{配置数最低}-{配置数最大}] {配置するアイテムID}^{出現割合}, {配置するアイテムID}^{出現割合},
	```
	- `start-level` はデバッグ用のゲーム開始レベル。省略時はレベル1から開始する。
	- `start-floor` はデバッグ用のゲーム開始フロア。省略時は1Fから開始する。
	- `start-item` はゲーム開始時に所持するアイテムID。カンマ区切りで複数指定でき、省略時は所持品なしで開始する。
	- `|モンスターハウス確率|` はモンスターハウスが生成される確率（%）。省略時は生成しない。
	- {出現割合}は、スポーンするときにその敵が抽選される割合で、
		すべての出現する敵で合わせて100%になる数値。
